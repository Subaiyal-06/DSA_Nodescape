# AVL Tree and Time Complexity - Syed Abdullah Hussain (CT-25283)

Classes: AVLTree (derived from BST), ComplexityAnalyzer, main menu.

- AVL: balance factor = height(left) - height(right); LL, RR, LR and RL rotations keep the height O(log n).
- Complexity: counts real worst-case steps for linear search, binary search and bubble sort.
