# Linked Lists - Muhammad Subaiyal (CT-25270)

Classes: Node, SinglyLinkedList, DNode, DoublyLinkedList, CircularLinkedList.

- Singly: insert front / end / position, delete, search, reverse (O(n)).
- Doubly: head and tail pointers, so end insert and delete are O(1); backward display.
- Circular: only a tail pointer is kept, head is tail->next.
