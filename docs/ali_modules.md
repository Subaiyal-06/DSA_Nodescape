# Stack, Queue and Array ADT - Mohammad Ali Ahad (CT-25269)

Classes: ArrayStack, LinkedStack, isBalanced, CircularQueue, LinkedQueue, ArrayADT.

- Stack: push / pop / peek in O(1), overflow and underflow handled, bracket checker.
- Queue: circular array uses % capacity to reuse slots; linked queue keeps front and rear.
- Array ADT: insert and delete shift elements (O(n)), linear search O(n), binary search O(log n) on sorted data, bubble sort O(n^2).
